# 否定対比（最優先パターン）

生成 AI の日本語で最も目につく癖。否定してから肯定し直す構文を、1 回出ただけでも書き換え対象にする。人間も使う構文だが、AI は人間の約 3 倍の頻度で使うという推定がある（The Atlantic, 2026-07）。「洞察っぽく見える」形が強化学習で好まれた結果とされている。

## 検出する変種

| 変種 | 例 |
|---|---|
| 一文の対比 | 「XではなくYだ」「XではなくYです」 |
| 文をまたぐ対比 | 「Xではない。Yだ。」「問題はXではない。Yだ。」 |
| 説明の「のだ」 | 「Xのではない。Yのだ。」「Xしたのではない、Yしたのだ」 |
| 格下げ | 「単なるXではない」「ただのXではなく」 |
| 言い換え | 「XというよりY」「XよりむしろY」 |
| 留保の否定 | 「Xわけではない。」の後に本題を続ける形 |
| 添加 | 「XだけでなくYも」「XのみならずYも」 |
| 否定の列挙 | 「Xでもない、Yでもない、Zだ」 |
| 末尾の短い否定 | 「〜。迷わない。」「〜。Xは不要。」「〜、推測は要らない。」 |
| 理由の対比 | 「Xだからではなく、Yだからだ」 |
| 否定から成功への言い換え | 「失敗したのではない。届いたのだ。」 |

見出し、タイトル、箇条書きの中にあっても対象にする。

## 残してよい条件

次のどれかに当たるときだけ否定を残す。当たらないなら書き換える。

- 読者が実際にその誤解を持っている。依頼文に書いてある、会話でそう言われた、広く知られた通説がある、のどれか。否定するときは根拠を一文添える
- 範囲や仕様を限定している（「本番には適用しない」「対象外」「暗号化しない」）
- 否定側にも情報がある。X が否定されること自体を読者が知る必要がある（例: 「DB の待機イベントは平常値だった」は調べた事実として残す）
- 引用、作品名、構文そのものを論じている箇所

## 書き換えの戦略

1. Y だけを書く。X を消しても意味が通るなら消す
2. Y に根拠や数値を付ける。X を否定する代わりに、Y が成り立つ証拠を置く。入力に根拠や数値が無ければ作らずに〔要確認: 何の数値か〕と残し、書き手に確かめる（下の例の数値は説明用）
3. X を否定する必要があるなら、否定の理由を事実として書く。「X ではない」と言わず「X を調べたら〜だった」と書く
4. 反実仮想を使う。「X が原因なら〜のはずだが、〜だった」
5. 比較なら、比較の軸と両方の値を書く

## 書き換え例

| 元の文 | 書き換え | 戦略 |
|---|---|---|
| これは単なるツールではなく、運用を変える仕組みです。 | このツールを入れてから、手動の承認作業が週 5 件から 0 件になりました。 | 2 |
| 問題はコストではない。体制だ。 | 止まっているのは担当者が決まっていないからで、予算はすでに付いています。 | 1・2 |
| 原因は DB ではなくネットワークでした。（読者が DB を疑っていない） | 原因は VPC 間の経路設定でした。 | 1 |
| 原因は DB ではなくネットワークでした。（読者が DB を疑っている） | DB の待機イベントは平常値だったので、経路設定を調べました。 | 3 |
| 目的はアラートを減らすことではありません。見逃しを無くすことです。 | 目的は見逃しを無くすことで、ノイズのアラームを止めるのはそのための手段です。 | 1 |
| 障害というより仕様の誤解です。 | 設定どおりに動いていて、仕様の理解が依頼側と食い違っていました。 | 1 |
| 失敗したのではない。必要な人に届いたのだ。 | 申込は 12 件で、そのうち 9 件が対象顧客でした。 | 2 |
| パッチ適用だけでなく、再起動も必要です。 | パッチを当てたあとで再起動します。 | 1 |
| キャッシュの問題ではない。 | キャッシュが原因なら、消した直後に直っているはずですが、症状は続いています。 | 4 |
| 手順書を読めば迷わない。 | 手順書に、判断が要る箇所ごとの基準を書いた。 | 1 |

## 書き換えた後の確認

- 否定を消して空いたところに、別の決め台詞（体言止め、「それが答えだ」）を入れていないか。癖を禁止すると別の癖が出やすい
- 次の正規表現で残りを拾い、残したものが「残してよい条件」に当たるか一つずつ確かめる。です・ます形（ではありません、わけではありません）も当たる。動詞の短い否定（「迷わない」「困らない」）は正規表現で拾えないので、文末を目視で見る

```text
ではな|じゃな|ではありません|でもありません|でもない|というより|よりむしろ|単なる|ただの|だけでなく|のみならず|わけでは|は不要|要らない
```
